# 🎧 Dom Casmurro Audiobook Player

Um projeto simples de player de audiobook criado utilizando HTML, CSS e JavaScript puro. O objetivo principal deste projeto foi **treinar a interatividade com o DOM e manipulação de eventos em JavaScript**, transformando a clássica obra de Machado de Assis em uma experiência de áudio.

## 📖 Sobre o Projeto

O projeto consiste em uma página web que reproduz o audiobook do livro **"Dom Casmurro"**. A obra é fornecida pelo **LibriVox.org**, uma fonte de audiobooks de domínio público.

O foco foi manter o código enxuto e didático, ideal para iniciantes em JavaScript.

### Funcionalidades Implementadas:

* **Controles de Mídia:** Reproduzir (Play), Pausar, e Pular para a faixa anterior/próxima (Back/Next).
* **Controle de Faixas:** Exibição dinâmica da faixa que está sendo reproduzida.
* **Design Simples:** Interface minimalista e focada na reprodução do áudio (conforme a imagem de capa).

## 🛠️ Tecnologias Utilizadas

* **HTML:** Estruturação da página e dos elementos de mídia.
* **CSS:** Estilização (fundo azul, centralização, ícones de controle).
* **JavaScript:** Lógica principal para:
    * Manipular o elemento `<audio>`.
    * Atualizar o estado dos botões (ex: mudar o ícone de Play para Pause).
    * Gerenciar o índice das faixas.
    * Atualizar a informação de faixa exibida no DOM.
